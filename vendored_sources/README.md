# Vendored sources

Frozen third-party data the dictionary is built from, one folder per source (`vendored_sources/{name}/`).

Every folder contains a `README.md` with:

* Origin: URL (and commit / version) the data was copied from
* License of the data
* Date it was retrieved

## japanese-vocabulary-pronunciation-audio

* Origin: [tofugu/japanese-vocabulary-pronunciation-audio](https://github.com/tofugu/japanese-vocabulary-pronunciation-audio)
  at commit `9725e0e` (2019-09-20), its last commit; `README.md` and `LICENSE` are the repo's own
* `mp3/`: 6,355 words, `ogg/`: 5,461 words, named `{word}【{reading}】.{ext}`
* License: CC BY-SA 4.0 (Tofugu Inc. and WaniKani)
* Retrieved: 2026-10-18
